# Mag-Linux
Ham radio tools for Linux used by MAGNET

This will have multiple tools available for operators to get. Below are the list of things that will be included in this build.

Ardop
ARIM, gARIM, vARIM 
AX25
Chirp
Direwolf
FL Suite
GPS & GPS Update
HAMLIB
JS8Call & JS8Spotter
Pat & Pat Menu
WSJT-X Improved
YAAC

# Instructions on how to download

Click on Releases
Right click and copy link address on the .tar.gz file

Open up Terminal on your computer and type:
wget "paste link"

(IE: wget https://github.com/MAGNET-HF/..)

# Unpackage file
tar -xzf "filename"

# Change directory
cd "Name of Directory"

cd /scripts

# Run install script
./install.sh

Give this time to run everything. This is going to download and install all of the programs and configurations that is needed onto your system.
